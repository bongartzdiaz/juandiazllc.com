# SEO audit — juandiazllc.com (2026-06-03)

2026 SEO strategist pass: organic discoverability, AI/LLM-readiness,
international targeting (EN/ES/DE), B2B operator-consultancy funnel.
Derived from code + modern audit checklists. No assumptions about live
rankings/backlinks (out of scope + unavailable).

## 1. Goals & ICP
- ICP = **operators** (decision-makers in energy, real-estate, hospitality +
  adjacent) at a build-vs-buy / instrument-vs-SaaS decision — not random traffic.
- Funnel = signal (insight) → sector (service) → work (proof) → contact. Exists
  and is well-structured.
- Markets: site is 4-locale (en/nl/de/es); positioning = "fractional revenue
  operator"; priority EN/DE/ES, NL secondary.
- **Tie SEO to business metric**: contact-form-submits + pricing/sector CTA
  clicks (Plausible goals), not sessions. That measurement is largely missing.

## 2. Technical SEO
Strong base. Issues: (a) verify `/` → `/[locale]` redirect + x-default; (b)
`translate()` EN-fallback risks thin/near-duplicate content under `/de`,`/es`;
(c) `/status` metadata — FIXED (noindex). Top fixes: root-redirect check,
i18n key-parity CI check, prod Lighthouse on home (Globe), GSC sitemap submit.

## 3. Rendering & AI
Ahead of most B2B sites: RSC (content in raw HTML pre-JS), Globe lazy below-fold,
`robots.ts` explicitly allows AI crawlers (GPTBot/ClaudeBot/PerplexityBot/…) with
a dedicated AI_ALLOW + PRIVATE_DISALLOW (CRM hidden), `llms.txt` present. Improve:
keep llms.txt current with positioning + key signals/cases; `dateModified` on
BlogPosting; definitive opening sentence per insight/sector (answer-box).

## 4. International (EN/ES/DE)
- EN strongest. **ES + DE underserved**: UI translated but content is NL-market-
  skewed (Zwolle, saldering) and insights appear to be one non-localized set
  (mixed EN/NL titles) served under all locales → thin for DE/ES.
- hreflang solid: `/[locale]/path` + sitemap `alternates.languages` + `x-default`;
  23/24 pages use `alternates`.
- **Biggest opportunity**: localize the language-agnostic operator-decision
  insights (build-vs-buy, instruments-not-SaaS, CRMs-fail-90d, dashboards-lie)
  into real DE/ES; mark NL-market insights (saldering, thuisbatterijen) NL-only
  via hreflang instead of EN-fallback.

## 5. On-page & content
- Good: insights hit real operator decisions; sectors have seoTitle + Service
  schema + FAQ; funnel is logical.
- Gaps: **/sectors is the weakest-linked funnel layer** (not in nav OR footer);
  no canonical "Services" page for the core fractional-operator offering;
  DE/ES lack market-specific sector landings.
- Pages to fix: (1) /sectors + /sectors/[slug] — add to nav/footer; (2) home —
  Service schema + operator-intent H1/title; (3) /work/[slug] — CreativeWork
  schema + sector cross-link; (4) insights — DE/ES localization; (5) new
  /services hub.

## 6. Architecture & internal links
Nav + footer cover the funnel except **/sectors is quasi-orphan** globally.
Add /sectors to nav+footer; add /work/[slug] → /sectors/[slug] cross-links;
/signals/[slug] → relevant /insights + /work. Anchor text already descriptive.

## 7. Schema
Coverage broad: Organization+Person+WebSite (layout), Person (about),
ContactPage+ContactPoint+FAQPage (contact), CollectionPage+Breadcrumb (insights,
sectors), BlogPosting+Breadcrumb (insight detail), Product+AggregateOffer+
FAQPage+Breadcrumb (pricing), Service+FAQPage (sector detail), Breadcrumb
(work detail), FAQPage (home).
- Fix: **sameAs inconsistency** across layout (linkedin+instagram), article.ts
  (github+linkedin+instagram), about (github only) → unify via one SSOT.
- Add: CreativeWork on /work/[slug] (only breadcrumb today); ProfessionalService
  on home/services; validate Org logo + Person sameAs in Rich Results Test.
