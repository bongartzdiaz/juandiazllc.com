## Quality issues

Sample-checked 10 NL, 5 DE, 5 ES strings. Findings:

1. **DE `form.*` uses informal `du/dich`, rest of DE uses formal `Sie`.** Brand cadence elsewhere in DE is formal ("Erzählen Sie mir, was Sie bauen.", "Wenn Sie das Kontaktformular absenden…"). Then the progressive form (`form.step1.title`, `form.step2.*`, `form.step3.*`, `form.submit`) drops to `du` ("Was betreibst du?", "Wo stehst du im Build?", "Wie erreichen wir dich?"). Pick one register and apply it consistently. Recommend: keep DE on `Sie` to match the rest of the site (NL stays on `je` per brand guideline). Lines 1828-1840 in `dict.ts`. Not a translation bug — a tone-consistency bug.

2. **ES `story.body.p1` (line 1867)** — `"Los míos me llamaban <em>el cazador.</em> El cazador. Paciente."` The repeated "El cazador. Paciente." reads awkwardly because in ES the literal translation already has "el cazador" right above it; the EN original works because "the hunter" is a clarifying gloss for non-Spanish readers. In ES, that gloss is redundant. Suggested fix: drop the second "El cazador." and start with "Paciente. Específico en lo que busco." (or replace with a connector like "El que persigue. Paciente."). Authorial choice — flag only.

3. **NL/DE/ES `cookie.body` (lines 750, 1347, 1944)** is partially stale: it still describes `"— als je accepteert — een privacyvriendelijke analytics-ping"` etc. The cookie banner itself was removed in Bundle 2 (CookieConsent.tsx deleted, Plausible loads unconditionally). The text is technically still true ("if you accept" via the `/privacy` opt-out toggle) but reads weirdly without a banner. Same story in DE (`"— wenn Sie zustimmen —"`) and ES (`"si acepta"`). The English en `cookie.body` (line 131) has the same issue. Worth a copy refresh on all four — minor cleanup, not a translation bug per se.

Other spot-checks (no issues found): `nav.*` (consistent across locales), `cd.*` countdown labels, `priv.h.*` headings, `roi.f.*` form labels, `impressum.*` (DE is canonical, NL/ES note that the German version is leidend/canónica — correct legal posture), `ventures.v*.*` (consistent venture cards across locales), `form.step2.*` survey/blueprint/build/operate phrasing (NL informal je, ES formal usted via `está`, DE informal du — see issue 1 above).

NL formality: brand uses informal `je`. Spot-checked `priv.p.contact` (uses `je`), `cta.lede` (uses `je`), `now.outro.1` (uses `je`), `roi.lede` (uses `je`) — consistent. ✓

ES formality: ES uses `usted` (`"Lo que este sitio sabe de usted"`, `"Si tiene cuenta"`) on privacy/legal pages and `tú` (`"Cuéntame qué estás construyendo"`, `"tu email"`) on cta/contact pages. Mixed by context — typical Spanish brand pattern (formal for legal, tú for direct outreach). Acceptable.
